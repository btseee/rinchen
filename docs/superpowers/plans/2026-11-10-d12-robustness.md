# D12 Robustness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure, on files and on a real tiny binary, what a model of ours does with numbers (value and format), placeholders, names, glossary terms, the script of its output and a source in traditional Mongolian script: six metrics as pure functions of rows, a strict suite file, a runner over the engine (or over a hypotheses file), the result `robustness.json` with one outcome per row, the command `rinchen eval robustness` with its manifest, a narrow `report.json` whose `robustness` block D13 and D15 embed, a deterministic toy a tiny model is trained on in 190 s, and the gate with its negative controls. Nothing is built that changes what a system does (no masking, no terminology engine, no request field).

**Tech Stack:** Python 3.14.10, Eole 0.6.4 (subprocess only, through the existing stages), CTranslate2 4.8.4 (through `Engine`), sentencepiece, sacrebleu, regex, typer, pydantic 2 (only where the repository already uses it), pytest + hypothesis. No new dependency.

## Open questions, recorded as such

1. **Mechanism and data.** No placeholder masker, no terminology engine, no `terminology` request field and no training rows that teach either exist after D12; the instrument does. Whoever builds them needs a data task first (all 100 placeholder indices, term markers) and a decision about the request schema (spec T1, section 6 item 1).
2. **GPU.** CTranslate2 on CUDA, float16, int8_float16 and their effect on these metrics: unmeasured.
3. **Real data and priors.** The conventions table, the 4-letter suffix, the currency symbols and the 0.98 floor are priors; no real model or corpus was measured; real entities have many spellings; number and magnitude words are not read.
4. **Real-data suites.** No generic builder from parallel text (shared numbers, masked placeholders, kept capitalised tokens); `entity_acc` and `term_acc` are `null` on sets without a table or a glossary; D13 decides.
5. **Format.** `numbers_acc` is value preservation; the format question is a detail, with no per-language rule beyond the table.
6. **The traditional script as a source.** Direct reading against a conversion: the instrument reports both arms; nothing decides which a product should use, and no real converter or script data exists.
7. **D15.** The tiny pipeline needs its own suite and matching training rows; D12's generator is a test helper; `placeholder_acc` 1.0 holds at beam 1 on the toy and not at beam 4 (599 of 600).
8. **Known over- and under-acceptance.** `Бат` matches `Батор`; a 5-letter suffix does not match; `10.30` is a decimal; digits glued to letters count; one `Engine.translate` call per run.
9. **The gate's cost.** The toy trains in 190 s and the whole module takes about 6 to 8 minutes on this machine; the full gate grows by that.
