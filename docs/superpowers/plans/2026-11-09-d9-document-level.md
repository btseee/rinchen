# D9 Document-Level Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build document-level training and inference: the vocabulary invariant that makes `<doc>`/`<sep>` usable, document windows (`docify`), a provenance-checked continuation of OUR teacher (`launch --continue-from`), the inference chunker with sentence-level fallback, and a tiny doc model that decodes `<sep>`-aligned output as the STOP gate.

**Architecture:** `eole_run` gains the reserved-symbol helper and the predictor length keys; `docify` + `doc_corpus` produce the doc corpora and the continuation config; `continuation` verifies a source checkpoint's provenance and the T6 checks; `launch` gains `continue_from`; `infer.doc_chunker` is a pure inference helper.

**Tech Stack:** Python 3.14.10, Eole 0.6.4 (subprocess only), sentencepiece, polars, pydantic v2, typer, pytest + hypothesis.

**Spec:** `docs/superpowers/specs/2026-11-09-d9-document-level-design.md` (binding; findings 1-8, rulings T1-T9). Spike evidence: `.superpowers/sdd/2026-11-08-d9-document-level/spike-findings.md` (scratch scripts and working configs named there). Master plan: `docs/research/2026-10-29-rinchen-dev-agent-prompt.md`, milestone D9.

- NO GPU: this machine has one that the owner did not authorise any use of; every Eole subprocess runs with `CUDA_VISIBLE_DEVICES=""` and `gpu_ranks: []`; nothing touches the GPU or NCCL.

Never tune on FLORES+ devtest or read any test split except where a test of the chunker reads the toy TEST documents on purpose (the gate): the ablation/continuation code itself never reads `test` rows.
- Tests before code; numeric and exact gates are gates (never loosen). Never weaken, skip or delete a failing test. Deterministic seeds everywhere; never silently drop a row, a window or a segment: every exclusion is counted under a reason.
- D5, D7 and D8 must not change behaviour except where a task says so; their tests stay green; edits to them are limited to import/patch targets a change makes necessary (list each).
- Commit subjects start with `D9: `; trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Gate: `uv run ruff format --check . && uv run ruff check . && uv run mypy src && uv run pytest -m "not network" -q` (never pass `-W error`; about 11 minutes: start it from a normal foreground shell or in the background, NOT inheriting ignored signals). No file mode changes. Match local style (`src/rinchen/train/`, `src/rinchen/cli/train*.py`).
- Invisible, control, look-alike and traditional-script characters in `.py` files only through `chr(0x....)`; visible Cyrillic letters are fine. Any path that reaches polars uses `glob=False`; paths given to Eole are refused when they hold `$`, `[`, `]`, `*` or `?`; blocking waits go through `run_logged`.
- Work on branch `d9-document-level`; do not merge, push or create branches.

## Review Focus

1. Vocabulary: a vocab file with some/all symbols present, duplicates, CRLF, a trailing-newline-less file, a count column format `token<TAB>count`, a symbol that is a prefix of another, a `src_vocab_size` smaller than the file, symbols containing `⟦n⟧` characters, concurrent calls (Task 1).
2. Windows: documents with gaps in `seg_idx`, duplicate `seg_idx`, unsorted input, one-sentence documents, a document longer than the budget, sentences with `<sep>` inside, empty/whitespace sentences, mixed directions with the same `doc_id`, doc ids that are empty/null, huge documents, determinism under row order and file order (Task 2).
3. Provenance: a step dir that is not final, a tampered weights file, a manifest of another stage, a manifest whose outputs name other files, an averaged dir without its manifest, a symlinked source, a source inside the new run dir, the source equal to the new run's own model_path, a manifest hash for a file that was legitimately re-written (Task 3).
4. Continuation attempts: the second attempt must drop `reset_optim`; an interrupted continuation resumes from its own step (not from the source); `train_from` smuggled through a base config or an override; the identity changes when the source changes (Task 3).
5. Chunker: any callable that returns the wrong count, extra/empty/duplicated segments, `<sep>` inside a segment, exceptions, whitespace-only documents, one sentence, a sentence over the budget, `max_sentences` 1, unicode separators (Task 4).
6. D7/D8 regression through the vocabulary change (the tiny teacher's weights sha, valid ppl numbers) and `predict_tokens` (Tasks 1, 5).
