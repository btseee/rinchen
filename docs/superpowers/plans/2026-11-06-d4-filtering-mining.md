# D4 Filtering & Mining Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the corpus Parquet contract, seven filter stages with an ordered pipeline, the B7 GlotLID wrapper, the B6 sentence aligner, a document matcher, and the `rinchen filter run` / `rinchen mine align` commands.

**Architecture:** Polars LazyFrame stages that add scores to a `scores` struct and set a first-failure `filter_reason`; models (LID, LaBSE, QE) sit behind protocols injected by the CLI; everything is tested with planted-failure fixtures and deterministic fakes, with real-model checks behind the `network` marker.

**Tech Stack:** CPython 3.14.10, polars 2.1.0, datasketch 2.0.0, fasttext-new 0.1.0 (module `fasttext`), sentence-transformers 6.2.0, sentencepiece 0.2.1, pydantic v2, typer, pytest + hypothesis.

**Spec:** `docs/superpowers/specs/2026-11-06-d4-filtering-mining-design.md` (read it; its "Stage semantics" table and "Rulings" are binding). Master plan: `docs/research/2026-10-29-rinchen-dev-agent-prompt.md` (section D4, B6, B7, `<contracts>`).

## Global Constraints

- Everything runs on CPython 3.14.x via `uv run ...`; never another Python or env.
- Tests are written before code; numeric gates (planted reason counts, recall >= 0.95, precision >= 0.95, aligner F1 >= 0.95) are never loosened to pass.
- The gate before every commit: `uv run ruff format --check . && uv run ruff check . && uv run mypy src && uv run pytest -m "not network" -q` (baseline on this branch: 124 files formatted, ruff clean, mypy 63 files, 938 passed, 6 deselected).
- Source files may contain visible non-ASCII letters (Cyrillic, Han, Hangul). Invisible, control, look-alike and traditional Mongolian characters must be written as `chr(0x....)` calls or as escape sequences put into the file through a scratch script: the Write/Edit tools convert backslash-u escapes in file content into raw characters. Check with `grep -nP '[^\x00-\x7F]' <file>` that only intended letters are raw.
- Match the repo style: `from __future__ import annotations`, module docstring, pydantic `ConfigDict(extra="forbid", frozen=True)` for configs, errors from `rinchen.errors` (ConfigError / DataError / UpstreamError), structlog via `rinchen.utils.logging.get`, no bare `except`, no `print` outside CLI.
- Never write under `data/` or `models/` from tests or probes; use `tmp_path`. Real-model tests (marker `network`) use the Hugging Face cache only.
- No new dependencies. Never fine-tune or continue-train any pretrained model (inference only). No Inner Mongolian data, no galig/Latin Mongolian, nothing about licensing or legal topics.
- Commit subjects start with `D4: `; end commit messages with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Do not change file modes. Do not touch `scripts/build_pyonmttok`.
- Do not dispatch subagents. Do not merge, push or create branches.

## Review Focus

- Empty or whitespace-only `src`/`tgt`: length score null with reason `len_ratio_char`, script share 1.0 (vacuous), numbers equal, LID/LaBSE do not crash (Task 4, 6, 7).
- Text in scripts outside `Script` (Greek, Arabic) and Latin brand names inside Cyrillic text: counted in the denominator only; 10% Latin is tolerated (Task 4).
- A language code that is not in `configs/languages.yaml`: `DataError` naming the code, never `KeyError` (Task 4, 7).
- Digits in other forms: Mongolian `U+1810..U+1819`, fullwidth, Arabic-Indic, CJK numerals, separators `1,5` / `1.5` / `1 000` (Task 4).
- An empty corpus (0 rows) through every stage, the pipeline and both CLIs; a corpus whose rows were all rejected; re-running with unchanged inputs (Task 9, 11).

- Produces: `script_ratio.script_share(text: str, scripts: Collection[Script]) -> float` (sum of `script_of(text)` shares over `scripts`; 1.0 when the text has no letters); `script_ratio.apply(df: pl.LazyFrame, cfg: ScriptRatioConfig) -> pl.LazyFrame`; `numbers.digit_multiset(text: str) -> Counter[str]`; `numbers.apply(df: pl.LazyFrame) -> pl.LazyFrame`; `length.effective_length(text: str, weights: Mapping[Script, float]) -> float`; `length.apply(df: pl.LazyFrame, cfg: LengthConfig) -> pl.LazyFrame`. A row whose language code is not in the registry raises `DataError` naming the code (script_ratio only).

Pinned behaviour:
- `script_ratio.apply` writes `scores.script_src` / `scores.script_tgt` using the registry scripts of `src_lang` / `tgt_lang`; flags `script_src` first, then `script_tgt` (a row failing both gets `script_src`) when the score is below `cfg.min_ratio`.
- `numbers`: every Unicode decimal digit becomes its ASCII digit (`unicodedata.decimal`); CJK numeral runs (characters `U+3007 U+96F6 U+4E00 U+4E8C U+4E09 U+56DB U+4E94 U+516D U+4E03 U+516B U+4E5D`, multipliers `U+5341`=10 `U+767E`=100 `U+5343`=1000 `U+4E07`=10000) are replaced by the digits of their value before counting: a run of one digit character that is not a multiplier is ignored; a run without multipliers is positional (`U+4E8C U+3007 U+4E8C U+56DB` -> `2024`); with multipliers it is summed (`U+5341 U+4E8C` -> `12`, `U+4E8C U+5341` -> `20`, `U+4E8C U+5341 U+4E94` -> `25`, `U+4E00 U+767E U+4E8C U+5341 U+4E09` -> `123`, `U+4E09 U+5343` -> `3000`, `U+4E00 U+4E07 U+4E8C U+5343` -> `12000`, a lone `U+5341` -> `10`, a lone `U+767E` -> `100`, a lone `U+4E00` and a lone `U+4E94` -> ignored). These eleven cases were checked with a prototype. `scores.num_ok` is true when the two multisets are equal; false rows get reason `numbers`.
- `length`: `effective_length` sums `weights.get(script, 1.0)` over every non-whitespace character, the script of a character being that of `script_of(char)` (a character without a script, such as a digit or punctuation, weighs 1.0); the weight of a letter whose script is not in `Script` is 1.0. `scores.len_ratio = effective_length(tgt) / effective_length(src)`, null when either is 0. Bounds come from `cfg.by_direction[f"{src_lang}->{tgt_lang}"]` when present (its `char_ratio` / `token_ratio` replace the defaults individually), else `cfg`. Char check: ratio null or outside `[min, max]` -> `len_ratio_char`. Token check (only when `cfg.spm_model` is set; the model is loaded once with `sentencepiece.SentencePieceProcessor(model_file=...)`; a missing file is `ConfigError`): `len(encode(tgt)) / len(encode(src))` outside the token bounds, or either token count 0 -> `len_ratio_token`; it is evaluated after the char check, so a row failing both gets `len_ratio_char`. There is no token score column.

### Task 5: `minhash` near-duplicate stage

**Files:**
- Create: `src/rinchen/filter/minhash.py`
- Test: `tests/unit/test_filter_minhash.py`

**Interfaces:**
- Consumes: `MinHashConfig`, `flag`, `FilterReason.DUPLICATE`, `PlantedCorpus`.
- Produces: `minhash.apply(df: pl.LazyFrame, cfg: MinHashConfig) -> pl.LazyFrame`; `minhash.duplicate_flags(texts: Sequence[str], alive: Sequence[bool], cfg: MinHashConfig) -> list[bool]` (pure helper: `True` for a text that duplicates an earlier alive text).
